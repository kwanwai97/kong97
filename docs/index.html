🙋 關於你

系統會根據呢啲資料，給你個人化建議。

風險偏好：你遇到新機會時，通常點樣？

📚 加入 3 筆個人資料

系統會記住呢啲資料，唔使你每次重複解釋。

點填：每筆有 3 個欄位。
key = 名稱，value = 內容，category = 分類
推薦 3 筆：
1. key:城市 value:香港 category:個人
2. key:興趣 value:打字員 category:個人
3. key:目標 value:減肥 category:目標

🎯 記錄你今日第一個決定

做咗任何決定就打上來。系統會開始學習你嘅模式。

理由：點解揀呢個（可空）
